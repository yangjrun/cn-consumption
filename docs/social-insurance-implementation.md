# 六城社保规则与年度联动

范围：2026 年普通企业在职职工，全年同城连续参保，公积金保持手工配置。逐月逐险种明细统一用于年度缴费、个税扣除、到手收入与单位成本。旧模型保留手填费率。

## 界面扩展决策

采用 Extension 模式，延续 [现有品牌规范](brand-spec.md)。新增内容服务于缴费选择、明细核对和来源追溯；面向手机和桌面阅读，保持安静、严谨的账本风格。

- 设计读数：视觉变化 2/10、动效 2/10、信息密度 7/10、图片依赖 1/10、品牌保真 10/10。
- 沿用纸色背景、墨色正文、社会缴费青和估算金；Noto Serif SC 标题、Noto Sans SC 正文、IBM Plex Mono 金额。
- 沿用 8px 间距节奏、6px 控件圆角、10px 面板圆角；阴影仅用于现有弹层。
- 保留五个入口、存储键、旧深链与保存流程。缴费步骤内增加模式、参保条件、单位费率和分时段明细。
- 明细表在小屏局部滚动，页面与弹层不横向溢出；验收 1440×900、1280×720、390×844。

政策核验、独立算例和最终验收结果随实施补充。
