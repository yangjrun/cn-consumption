# 税镜品牌与界面规范

## 识别资产

- 现有字标：红色方印“税” + “税镜”中文名称 + “个人年度税费账本”产品描述。此字标来自既有产品，不替换为外部图标或临时插画。
- 产品不依赖摄影或插画；识别主要由中文编辑排版、细分隔线、金额等宽字体与税费语义色构成。

## 设计系统

- 背景：纸色 `#F3F0E8`，抬升面 `#FAF8F2`，深纸色 `#E8E3D8`。
- 文字：墨色 `#171915`；税费红 `#B3442F`；社会缴费青 `#316B70`；估算金 `#856128`。
- 字体：Noto Serif SC 用于标题，Noto Sans SC 用于正文，IBM Plex Mono 用于金额和时间刻度。
- 间距：8px 基准；控件圆角 6px，面板圆角 10px；阴影只用于抽屉、确认框和即时反馈。
- 动效：160–240ms，只表达状态切换、结果变化或操作成功；遵循 `prefers-reduced-motion`。

## 体验契约

- 税、社会缴费、价格内含税和扩展观察必须在颜色、文案与汇总中严格分离。
- 示例数据必须明确标记，不得表现为用户真实结果。
- 所有一次性场景先试算、后确认写入，并展示写入前后的影响。
- 所有金额保留计算依据、可信度或无法确定的边界，不用装饰性精确数字填补缺口。
- 保留旧 `view` 深链的兼容映射、旧本地数据迁移与浏览器前进/后退行为。
